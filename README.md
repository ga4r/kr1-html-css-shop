# RunSmart — магазин пульсометров

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина пульсометров и спортивных часов RunSmart. Сайт вымышленный и сделан в учебных целях. На нём можно посмотреть каталог, открыть карточку товара с характеристиками и сравнением моделей, оставить заявку, узнать условия доставки и связаться с магазином.

Проект сделан на чистых HTML и CSS, без CSS-фреймворков и без JavaScript. Модальное окно, FAQ и блок «Ваша заявка» работают на CSS. Папки `js/` в проекте нет: методичка допускает `js/main.js` только для модального окна, а здесь оно сделано на CSS.

## Используемые технологии

- HTML5: семантическая разметка, формы со встроенной валидацией, `<details>`/`<summary>`, таблицы.
- CSS3: переменные (`:root`), псевдокласс `:target` для модального окна, Flexbox, CSS Grid, `position` (`relative`/`absolute`/`sticky`/`fixed`), `z-index`, псевдоклассы `:hover`, `:focus-visible`, `:focus-within`, `:user-invalid`, `:has()`, медиазапросы.
- Методология БЭМ для именования классов.
- Git, GitHub, GitHub Pages.

## Где выполнены требования методички

| Требование | Где реализовано |
|------------|-----------------|
| Семантика `header`, `nav`, `main`, `section`, `article`, `aside`, `footer` | На каждой странице один `main`. Карточки товаров и отзывы — `article`, фильтры, итог заявки и блок помощи — `aside` |
| Единая навигация | Одинаковое меню `site-nav` во всех страницах. Активный пункт — модификатор `site-nav__link--active` и `aria-current="page"` |
| Якорные ссылки | `index.html#advantages`, `#popular`, `#reviews`, `#contacts` (в подвале), `catalog.html#fitness` и др., меню разделов на странице товара, `contacts.html#faq` |
| Карточки товаров | Блок `product-card`: название, описание, цена, старая цена, «Подробнее», «В заявку», бейджи |
| Таблица с `caption`, `thead`, `tbody`, `th`, `td` | `product.html` — характеристики и сравнение моделей; `delivery.html` — условия доставки |
| Форма | `order.html` и `contacts.html`: у каждого поля `label` с совпадающими `for`/`id`, атрибуты `name`, `required`, `type="email"`, `type="tel"` с `pattern` |
| Модальное окно | CSS-модалка «Заказать звонок» (`#callback-modal`), есть на всех страницах. Открывается ссылкой `href="#callback-modal"` через `:target`. Крестик и клик по фону — ссылки на `#close`, окно скрывается. Позиционирование `fixed`, `z-index: var(--z-modal)` |
| CSS-переменные | Блок `:root` в начале `css/style.css`: цвета, отступы, скругления, шрифты, тени, слои `z-index` |
| `:hover` и `:focus-visible` | Кнопки, ссылки меню, карточки, поля форм, FAQ, соцсети. Общий видимый фокус для всех элементов |
| Flexbox | Шапка, меню, группы кнопок, содержимое карточек, хлебные крошки, подвал |
| CSS Grid | Сетки карточек (`product-grid`), каталог «фильтры + товары» (`catalog-layout`), страница товара, форма (`form__grid`), заявка, контакты, подвал |
| БЭМ | `site-header__inner`, `site-nav__link--active`, `product-card__price`, `product-card--discount`, `form__field`, `badge--sale` и т. д. |
| `position: relative` | `product-card`, `hero`, `cta`, `steps__item`, `product__main` |
| `position: absolute` | Бейджи «Хит», «Скидка», «Новинка» в карточке; затемнение фона hero; номера шагов |
| `position: sticky` | Шапка сайта, фильтр каталога, меню разделов товара, блок «Ваша заявка» |
| `position: fixed` | Кнопка «Наверх» |
| `z-index` | Шапка, sticky-фильтр, кнопка «Наверх», бейджи, skip-link. Значения вынесены в переменные `--z-*` |

## Самостоятельные доработки

1. **Дополнительные страницы.** «Доставка и оплата» с таблицей условий и блоком гарантии и страница «Заявка принята». Все формы ведут на неё, поэтому сценарий заявки доводится до конца.
2. **Собственное визуальное оформление.** Фирменный красный цвет, логотип-знак с пульсовой линией, фоновые фото с затемнением, единая система отступов и скруглений на переменных.
3. **Карточки через БЭМ-модификаторы.** `--discount` (цена красным), `--unavailable` (серое фото и неактивная кнопка «Нет в наличии»), `--featured` (широкая горизонтальная карточка). Отдельный блок `badge` с модификаторами `--hit`, `--sale`, `--new`, `--muted`.
4. **Структура каталога.** Хлебные крошки на внутренних страницах, категории с количеством товаров, sticky-фильтр, панель сортировки, разделы по категориям.
5. **Страница товара.** Галерея, расчёт выгоды, sticky-меню по разделам, таблица сравнения с выделенной колонкой текущего товара, отзывы, похожие товары, блок помощи.
6. **Улучшенные формы.** Группировка через `fieldset`/`legend`, выбор способа доставки карточками-радиокнопками, подсказки под полями. Сообщения об ошибках появляются только после взаимодействия с полем (`:user-invalid` + `:has()`). Атрибуты `autocomplete`, кнопка «Очистить форму».
7. **Блок «Ваша заявка» реагирует на форму без JavaScript.** Селектор `.order-layout:has(option:checked)` показывает фото, название и цену выбранного товара, а `:has([name="delivery"]:checked)` — выбранный способ доставки. Итоговую сумму CSS посчитать не может, поэтому блок честно сообщает, что сумму с учётом количества назовёт менеджер. Живой пересчёт запланирован в КР №4, где добавляется JavaScript. В браузерах без `:has()` остаётся вариант по умолчанию (`@supports selector(:has(*))`).
8. **Модальное окно без JavaScript.** CSS-модалка на `:target`: плавное появление, размытый фон, закрытие по «×» и клику по фону. Пока окно закрыто (`visibility: hidden`), его поля недоступны с клавиатуры.
9. **Блоки отзывов и FAQ** на `<details>`/`<summary>` без JavaScript.
10. **Доступность.** Ссылка «Перейти к содержимому», видимый фокус, `aria-current` в меню и крошках, подписи у всех полей, `alt` у изображений, скрытый текст для цен и рейтинга, учёт настройки `prefers-reduced-motion`.
11. **Работа с изображениями.** Все фото переведены в WebP (весь проект вместе со шрифтами весит меньше 1 МБ). У картинок указаны `width`/`height`, картинки ниже первого экрана загружаются лениво (`loading="lazy"`).
12. **Базовая адаптивность.** Сетки перестраиваются на планшете и телефоне, горизонтальной прокрутки нет. Полная адаптация запланирована в КР №3.
13. **Качество кода.** HTML проверен валидатором `html-validate` без ошибок. CSS разбит на пронумерованные разделы с комментариями.
